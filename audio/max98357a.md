# Adafruit MAX98357A I2S Mono Amplifier

Source: https://learn.adafruit.com/adafruit-max98357-i2s-class-d-mono-amp/pinouts

I2S Class-D mono amplifier breakout. 3.2W into 4 ohm, 1.8W into 8 ohm. 2.5V-5.5V input.

## Pinout (header at top, speaker terminal at bottom)

```
         ┌─────────────┐
     VIN │ 1         7 │ SD
     GND │ 2         6 │ GAIN
      SD │ 3         5 │ DIN
    GAIN │ 4         4 │ BCLK
     DIN │ 5         3 │ LRC
    BCLK │ 6         2 │ GND
     LRC │ 7         1 │ VIN
         └─────────────┘
```

Note: The board has a single 7-pin header along one edge. Pins are numbered
1-7 from left to right when the header is at the top, component text readable.

```
    Header (component facing you, text readable)
    ┌───────────────────────────────┐
    │ 1    2    3    4    5    6   7│
    │VIN  GND  SD  GAIN DIN BCLK LRC│
    │                               │
    │        MAX98357A              │
    │                               │
    │  [+]                  [-]     │
    └───────────────────────────────┘
         Speaker screw terminal
```

## Pin Description

- VIN -- Power input, 2.5V to 5.5V
- GND -- Ground
- SD -- Shutdown and channel select. Internal 100K pulldown. Float or pull high for stereo average (left+right)/2. Tie to GND to shut down. Connect to logic pin for software shutdown control.
- GAIN -- Amplifier gain select. Float = 9dB. 100K to GND = 12dB. 100K to VIN = 6dB. Direct GND = 15dB (may distort). Direct VIN = 3dB.
- DIN -- I2S serial data input
- BCLK -- I2S bit clock input
- LRC -- I2S left/right channel clock (word select)

## Speaker Output

3.5mm screw terminal block (2 positions: + and -).
Bridge-tied load output -- no ground reference on speaker pins.
Connect 4-8 ohm speaker directly. Do not connect either terminal to GND.

## I2S Interface

- No MCLK required (internal clock recovery)
- Supports 8kHz to 96kHz sample rates
- 16-bit or 32-bit data
- Standard I2S format (Philips)

## Channel Select (via SD pin)

- SD float (100K pulldown active) = (L+R)/2 mono mix
- SD to VIN via 100K = Right channel only
- SD to GND via 100K = Left channel only
- SD direct to GND = Shutdown (low power)
