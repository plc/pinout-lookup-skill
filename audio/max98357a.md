Pin header (1-7, left to right):

| # | Label | Function            |
|---|-------|---------------------|
| 1 | Vin   | Power supply        |

Speaker output: screw terminals (separate from header).

## Pin Descriptions

- **Vin** -- Power supply, 2.5-5.5V. Recommend 800mA+ capacity for full output.
- **GND** -- Ground reference.
- **SD** -- Shutdown and stereo/mono channel select. Has 1MΩ pullup to Vin on breakout (see SD Pin Behavior below).
- **GAIN** -- Amplifier gain setting (see GAIN Settings below).
- **DIN** -- I2S serial data input.
- **BCLK** -- I2S bit clock input.
- **LRC** -- I2S left/right clock (word select) input.

## I2S Interface

Standard I2S digital audio interface. No MCLK (master clock) required.

Typical wiring to MCU:
- DIN → I2S data out (DOUT/SD)
- BCLK → I2S bit clock (SCK/BCK)
- LRC → I2S word select (WS/LRCK)

Clock frequencies determined by sample rate and bit depth.

## SD Pin Behavior

The SD pin has a 1MΩ pullup to Vin on the Adafruit breakout. Voltage thresholds determine mode:

| SD Voltage Range | Mode                |
|------------------|---------------------|
| <0.16V (GND)     | Shutdown            |
| 0.16-0.77V       | Stereo average (L+R)/2 |
| 0.77-1.4V        | Right channel only  |
| >1.4V            | Left channel only   |
| Floating (at 5V) | Stereo average (L+R)/2 (default) |

For simple mono operation, leave floating or tie to Vin.

## GAIN Settings

Set gain via resistor to GND or Vin on GAIN pin:

| GAIN Connection | Gain  |
|-----------------|-------|
| 100KΩ to GND    | 15 dB |
| GND             | 12 dB |
| Floating        | 9 dB (default) |
| Vin             | 6 dB  |
| 100KΩ to Vin    | 3 dB  |

Default (floating) is 9 dB.

## Power and Output

- Input voltage: 2.5-5.5V
- Recommended supply capacity: 800mA+
- Output power: 3W into 4Ω, 1.5W into 8Ω
- Minimum speaker impedance: 4Ω

## Notes

- Fully digital input (I2S), no external DAC required
- Built-in click/pop suppression
- Thermal and short-circuit protection
- Breakout board includes ferrite bead and bulk capacitors for clean power
