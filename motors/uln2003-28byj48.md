# ULN2003 Stepper Driver Board + 28BYJ-48 Motor

Source: Physical module photo (verified pin header layout and silkscreen labels)

ULN2003AN 7-channel Darlington driver array for unipolar stepper motors. Commonly paired with 28BYJ-48 5V stepper motor. 5-12V motor power input, 5V logic input.

## Pinout (front view, motor connector at top)

```

                |   JST Connector  |
                |  [===========]   |
                |   (28BYJ-48)     |
                |                  |
                |  +-----------+   |
                |  |           |   |
                |  | ULN2003AN |   |    +---+
                |  |           |   |    | - | Motor Power (-)
                |  +-----------+   |    +---+
                |                  |    | + | Motor Power (+)

                |IN1 IN2 IN3 IN4 IN5 IN6 IN7

                  1   2   3   4   5   6   7
```

## Pin Description

### Bottom Header (7-pin, left to right)
- IN1 -- Driver input channel 1 (motor coil A)
- IN2 -- Driver input channel 2 (motor coil B)
- IN3 -- Driver input channel 3 (motor coil C)
- IN4 -- Driver input channel 4 (motor coil D)
- IN5 -- Driver input channel 5 (unused with 28BYJ-48)
- IN6 -- Driver input channel 6 (unused with 28BYJ-48)
- IN7 -- Driver input channel 7 (unused with 28BYJ-48)

### Right Side Header (2-pin, top to bottom)
- (+) -- Motor power positive (5-12V DC, typically 5V for 28BYJ-48)
- (-) -- Motor power ground

### Top JST Connector (5-pin white connector)
- 5-pin female connector for 28BYJ-48 motor cable
- Motor cable has keyed connector, can only insert one way
- Pinout handled internally by board; user only needs to plug in motor

## 28BYJ-48 Stepper Motor Specifications

- Type: Unipolar 5-wire stepper motor
- Rated voltage: 5V DC
- Step angle: 5.625° (64 steps per revolution of internal motor)
- Gear ratio: 1:64 (approximately, varies by manufacturer)
- Steps per output shaft revolution: 4096 half-steps (2048 full steps)
- Max torque: ~300 gf.cm
- Connection: 5-pin JST connector (plugs into ULN2003 board)

## Usage with 28BYJ-48

Only IN1-IN4 are used for the 28BYJ-48 stepper motor. These correspond to the four coils of the motor. The motor connects via the 5-pin JST connector on the board.

Typical stepping sequence (half-step mode, 8 steps per cycle):
1. IN1=HIGH, IN2-IN4=LOW
2. IN1=HIGH, IN2=HIGH, IN3-IN4=LOW
3. IN1=LOW, IN2=HIGH, IN3-IN4=LOW
4. IN1=LOW, IN2=HIGH, IN3=HIGH, IN4=LOW
5. IN1-IN2=LOW, IN3=HIGH, IN4=LOW
6. IN1-IN2=LOW, IN3=HIGH, IN4=HIGH
7. IN1-IN3=LOW, IN4=HIGH
8. IN1=HIGH, IN2-IN3=LOW, IN4=HIGH

## Power Requirements

- Motor power: 5-12V DC (5V recommended for 28BYJ-48)
- Motor current: ~200mA at 5V
- Logic input: 5V (not 3.3V tolerant on most boards)
- Separate power supply recommended for motor (do not power from MCU 5V pin unless current capacity is sufficient)

## LED Indicators

Four LEDs on the board indicate IN1-IN4 activity. LEDs light up when corresponding input is HIGH, providing visual feedback of motor stepping sequence.

## Notes

- This is the common 7-input variant with separate motor power pins on the right side
- Pin header layout varies by manufacturer; always verify against silkscreen labels on your specific board
- Some variants have different power connector positions (e.g., integrated with input pins)
- The 28BYJ-48 gear ratio is approximately 64:1 but varies between 63.68395:1 and 64:1 depending on manufacturer
- Most ULN2003 boards are NOT 3.3V logic compatible; use level shifters or 5V-tolerant MCU pins
- IN5, IN6, IN7 are unused with 28BYJ-48 but can be used for other loads (LEDs, relays, etc.) up to 500mA per channel
